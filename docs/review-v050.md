# 0.5.0 同一立体表身与连续升芯

四代手表改用本地 WebGL 几何渲染。俯视、左前、低角度、右前改变同一模型的观察方向；表带内外壁、护架、侧面构件均有三轴体积和深度遮挡。表芯单独沿轴升降，快速反向从当前高度继续。三种选择模式共用模型与原有目录，界面未新增自由环绕拖动，以保留左右滑动选英雄。

完成版表盘模式使用露盘但收芯的第三状态。无 WebGL 或上下文丢失时，保留已标注的多角度插画回退。画面变化结束后不继续请求动画帧，隐藏和退出时停止渲染并释放资源。模型代码已嵌入 preview，无新增外部运行依赖。

## 修复与证据

首轮浏览器检查发现模型过大造成舞台底部裁切；缩小表身并重新布局后核对完整表带。发现升芯短轴与底座脱离，已延长实际芯轴，使满升状态仍与固定套环重叠。逐顶点投影测试另捕获 UA 与完成版展开盖片越出画布，调远固定镜头后通过。完成版菱形表盘原先遮在闭盖之上，现先展开模型盖片。初稿括号错误暴露构建未先验证拼接脚本，构建现在在写出预览前执行脚本语法检查。

完整 npm test：**125/125 通过，0 失败、0 跳过**。其中 11 项模型测试覆盖四代真三轴网格、固定表身不重建/不漂移、连续反向升降、芯轴连接、减少动态、隐藏停绘、上下文丢失清理及 160 组姿态/模式的每个顶点入框。实际应用测试还覆盖模型锚点驱动转盘/屏面、回退继续选英雄以及退出后的迟到回调。

根代理实际查看 12 张最终构建截图：桌面实宽 1265，手机测试实宽 375 和 305；记录均无页面横向溢出，三种选择模式均出现。最终恢复正常动画并操作视角/连续升降，保留初代侧前方最终截图。浏览器本轮 error/warn 查询为空。部分截图因控件自动滚动只显示页面下部；不将截图边缘裁切冒充模型本身裁切，也不以这些静帧证明手机帧率。
