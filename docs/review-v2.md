# 0.2.0 交付验证记录

本版接入初代 Omnitrix、Alien Force 重校准款、Ultimate Alien 的 Ultimatrix 与 Omniverse 完成型四代表壳，使用 `assets/watches-v3`。图片为参考原作资料重绘的界面素材，不是官方原图；来源、生成提示词及原始文件哈希见该目录的 `provenance.json` 与 `prompts.json`。

界面保留全息投影、环形转盘、表盘剪影三种模式，宇宙记录墙已移除，旧记录墙偏好迁移为投影。形态目录仍为 **225 条记录、98 条已接入剪影、127 条待补素材**；本版没有把缺图计为已完成。

## 自动验证

`npm test`：**43 项通过，0 项失败，0 项跳过**。验证包括目录与离线资源完整性、三种模式的选择状态与动画取消、偏好迁移、缺图占位、焦点及键盘交互，以及构建内容与当前源码一致性。

- **98 项菱形适配**：90 张 PNG 使用真实非透明轮廓；8 张 AVIF 使用 SVG 过滤后的可见轮廓，独立解码核对安全包络、缩放值和边缘余量。原素材字节未修改。几何证明适用于当前符号视口及居中等比映射条件；实际显示位置仍需浏览器复核。
- **12 项手机安装工具测试**：在一次性目录验证首次安装、重复执行、半成品覆盖、无关文件与 `.git` 保留、下载及哈希失败、写入回滚、路径拒绝和中途退出后的再次修复。额外以真实 Windows 目录 junction 复现并修复路径别名导致 CLI 静默退出的问题，不跳过夹具创建。首次安装只放五个运行文件，不创建 `.git`，后续使用同一工具更新。逐文件覆盖不是断电原子事务。
- **4 项投影锚定测试**：注入不同表盘矩形，验证四代中心差异、窗口调整后的对齐、900 ms 跟踪结束、过渡中选择与确认继续剩余跟随、减少动态和离页取消。包含 UA 与初代中心相差 47 px 的回归情形；夹具不代替浏览器布局或像素检查。

四表图片检查同时验证原字节、尺寸、RGBA、真实透明像素及来源元数据。此前一轮为 40/41 通过，唯一失败来自测试额外要求 alpha 最大值必须精确为 255；新 UA 原图最大值实际为 254。已改为背景存在 alpha 0、主体最大 alpha ≥250，并继续逐项匹配实际元数据。没有通过改图片字节满足测试，也没有删除原有哈希、尺寸或透明像素检查。
