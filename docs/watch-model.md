# 手表体积模型与来源约定

当前四款手表使用用户指定的打印模型：第一槽为 Reboot 第一季 Omnitrix，其后为 Alien Force 重校准版、Ultimatrix 和 Omniverse 完成版。四款共 **14 个运行网格、165,994 个三角形**。各视角改变同一物体的相机方向；手表并非多张相互独立的平面图。源作者、许可证及官方发布身份尚未建立，不能因文件由用户提供就称为官方三维模型。

本轮选用注册表 SHA-256 为 `72be7a2a3b7c124b16d1a96e9995c6611d65ef0f8f7038bf92008aefdd6d7c5e`。运行元数据、文件哈希及部件能力见 [网格注册表](../assets/watch-meshes/registry.json)；原包、转换矩阵、减面参数、删去的零面积面与来源限制见 [来源记录](../assets/watch-meshes/provenance.json) 和 [转换回执](../assets/watch-meshes/conversion-receipt.json)。生成脚本与完整高模离线审计材料不随运行包自动分发。

## 原形保留与显示减面

Reboot 原 3MF 含 1,315,562 个三角，超过每表 150,000 面的加载预算。本轮在四个原件各自的源坐标中做 QEM 二次误差边折叠，得到手机显示用的 LoD：cuff 36,000、Dial 30,000、Core 48,000、button 6,000，合计 120,000。使用 PyMeshLab，保留边界、法线与拓扑约束；详细参数见回执。未使用体素重建、布尔填形或新增几何来替代原件。四个圆灯、表芯沙漏刻槽、护架、腕孔内壁及按钮来自原模型。

完整高模、全部原面正交视图与减面后的同相机对照是离线审计证据；手机运行加载的是 LoD，不能写成保留了全部 131 万源面。QEM 输出不与原面逐面等价；固定种子的双向表面抽样及轮廓对照也不是全表面 Hausdorff 上界。

AF、UA、OV 使用原三角坐标、刚体变换和各表统一缩放，不做重建、填沟或减面。AF 的 18,158 面与 UA 的 9,274 面完整保留。OV 七件选中源面合计 18,578 面，转为运行 float32 后恰好零面积的 16 面被省略，剩余 18,562 面；来源面索引逐项记录。UA 原侧槽及侧附件保留，作者对这些槽的机械用途未知。

法线在当前坐标上按相邻边建立连续的平滑扇区，对 40° 内相邻面使用角度加权角点法线；真实折角分开。法线计算不再移动或平滑几何顶点。源模型已有的交叠、非流形条件和细窄面没有被重建消除，不能据此声称所有部件水密、无自交或适合直接打印。当前默认已经撤回中途体素重建方案，不继承该方案的闭合或自交检查结论。

## 坐标、装配与运动边界

运行坐标以 X 为腕部轴、Y 为上方。Reboot 原 cuff 的腕孔轴为源 Z、盘座朝源 +Y；Dial 与 Core 的原 +Z 朝外，需要刚体转向盘座。源 3MF 的打印布局分开排放四件，`assemble_item` 也只把四件底面放到同一高度，不是可直接采用的机械装配。当前按原盘座约 39.14–39.35 mm 的表面及斜侧按钮座定位，四件共同使用 0.013 的统一缩放。具体位置、轴向及矩阵保存在回执中。

Reboot 的表盘、徽记和按钮都是实际原件表面；没有叠加新的黑盖、沙漏薄片、升降轴或轴侧标记。原 Core 的颈圈半径约 23 mm，而 Dial 最窄孔径半径约 20.624 mm，原件尚未证明机械互配。当前是有来源的展示装配，内部法兰与接触部位可能交叠；没有通过单独缩小某个原件来隐去尺寸差异，也不宣称布尔无碰撞或制造公差合格。

AF 保留所选 3MF 的完整对象及非打印组件变换，统一缩放为 0.0205。UA 保留整份 STL 的原相对位置，统一缩放为 0.016；三个独立侧件仍固定于原位置。两款均没有已确认的独立核心，所以几何升降为零，人物投影开关与机械动作分开处理。

OV 的七件通过测量圆轴、中心、旋转和位移进行项目装配，统一缩放为 0.02。完整单盖和腕带的定位仍含外观装配判断，源文件没有提供已确认的铰链或滑轨。只有实际独立的圆芯与面环参与升降，完整盖保持固定。源件存在及可以移动，不代表原作使用同一骨架、移动距离或时序。

## 预览材质与加载

本轮配色属于项目预览：按原部件及原表面特征指定橡胶、涂层、金属和发光类别，不恢复源 RGB，也不为分色增添三角。Reboot 护架和包边使用银色、四个原圆灯使用绿色；AF 使用原有徽记面与盘框着色；UA 主体采用绿色涂层、原侧件使用银色。三种界面能量配色仍由同一状态管理。

着色器使用程序计算的粗糙度、物体空间细纹和固定棚灯高光来区分材质。这是解析光照和程序纹理，没有使用扫描材料、实测 PBR 贴图或从源包恢复的反射参数。灯光不会增加真实几何厚度，也不能修补源面的交叠。

磁盘文件每顶点十个 float32、40 字节，保存位置、法线、线性 RGB 与材质类别。GPU 上传追加一个表面标签，共十一 float32、44 字节；源保留方案的标签为 0，避免误套中途重建表壳的空间分区规则。现有源部件只使用 body 与 core 运动组，当前没有左右滑盖组。

加载器按需校验字节数、坐标边界、单位法线和每表 150,000 三角上限；支持 WebCrypto 时校验内容 SHA-256。完整网格校验并上传后才替换当前备用模型。失败时明确保留回退状态；快速切表、隐藏停绘与销毁后的迟到请求沿用同一生命周期。这些运行能力不使源文件自动拥有相机、骨架或动画。

## 一套模型，一套选择界面

- 四款共用渲染器、相机与选择状态；俯仰、转向和缩放改变三维观察方式，不靠压扁图片表现水平放置。
- 表盘剪影、全息投影及头像转盘使用同一目录。切换模式保留所选形态，投影与屏面跟随对应表盘锚点。
- 可动能力遵守源件结构。固定表体不会为统一动画而凭空拆出核心；Reboot 与 OV 的独立表芯运动仍是项目绑定。
- APK 开表、英雄切换及确认时序目前只完成了[静态来源研究](dna-altering-motion-reference.md)，尚未接入正式交互。
- 历史 V3 单图和 V4 多视图是 AI 界面美术，也用于不支持 WebGL 时的回退；它们不是源三维文件或原作测量证据。

## 外观参考与历史建模约定

以下保留早期外观研究的来源与解释边界。它们不是当前打印模型的发布来源，也不要求改造原件去追随旧建模设想。当前第一槽按用户指定使用 Reboot 第一季源文件；下述初代近景不被改称该文件的官方出处。当前 AF／UA 无独立升芯，OV 单盖固定，能力以本文开头的源件表为准。

### 初代 Omnitrix

已核对的官方近景来自认证 Ben 10 频道的 [Swampfire Transformation Unlocked / Omnitrix Reconfigured，约 116 秒](https://www.youtube.com/watch?v=iLBivD9Pxks&t=116s)。画面展示重校准前的旧表：深色厚表体与宽带、浅灰弯曲护件、圆盘周围四个较小绿点，以及单独一个较大的绿色侧按钮。这个旧表画面出自 Alien Force 片段，不能改称 2005 版原集截图。

建模需把四个小指示点和大侧按钮作为不同构件；四根浅灰弯曲护架围绕圆形模块分布，保留圆盘框、深色托座与腕带之间的层次。大按钮固定在同一物理侧面，转动镜头不能让它左右跳换。

Cartoon Network UK 的 [Ben Discovers the Omnitrix，约 77 秒](https://www.youtube.com/watch?v=JlqkvF5GudE&t=77s) 另支持升起圆柱表芯及侧壁绿色标记。现有近景不足以量定完整腕带背面、扣具、准确厚度和俯视直径；这些尺寸由界面建模推定，不作为官方尺寸。

用户提供的初代腕表截图可补充可见外形，但转载水印和用户提供行为本身不证明官方发布链。初代挡片的已见动作与未验证范围继续见 [表盘动画参考](dial-animation-reference.md)。

### Alien Force 重校准 Omnitrix

同一官方视频的 [约 120 秒闭合状态](https://www.youtube.com/watch?v=iLBivD9Pxks&t=120s) 与 [约 124 秒升芯投影状态](https://www.youtube.com/watch?v=iLBivD9Pxks&t=124s) 支持以下特征：绿色腕带带黑色中线、紧凑的深蓝黑圆壳、绿色下层底座、两侧短圆柱控制件和前缘银灰弧形配件。近侧控制件的绿色端面在画面中明确可见。

闭合与升起应共用同一腕带和托座；升起部分为带绿色侧壁标记的深色圆柱。不能把初代四根护架、四个环周小灯或 Ultimatrix 的长护腕移到这一代。官方近景未展示完整背侧及展开尺寸，背面闭合方式、内壁厚度和精确比例仍是建模解释。

### Ultimatrix

现有结构参考是 [Pinclipart 托管的平面插图](https://www.pinclipart.com/picdir/big/394-3943027_cartoon-network-wiki-ben-10-ultimate-alien-omnitrix.png)。该图可读，但没有已核实的作者署名、原始官方发布页或制作栏；文件名含 Cartoon Network / Wiki 不构成官方认证。

图中是长的绿色空心护腕，圆盘偏长轴一端，另一端设深蓝灰矩形嵌块。圆盘外圈为有侧厚的灰色壳体；侧面长嵌板内有两根独立浅绿管，各有灰色端接头，一根弯回、一根沿长向延伸，不能合成 Y 形或共用接头。

早期建模要求圆盘始终留在同一物理端，未见的另一侧、内腔连续结构、精确锥度和背部接合方式属推定。当时附加的短距离升芯是界面设计，未由该参考证明；当前 UA 已恢复所选原整表，不保留该附加表芯。

### Omniverse 完成型 Omnitrix

参考为 [Ben10protector 的转载帖](https://x.com/Ben10protector/status/1831392265149018138) 中的 [三状态模型稿镜像](https://pbs.twimg.com/media/GWppjocW8AAegif.jpg)。图内有 Cartoon Network Studios、The More Things Change, Pt. 1、TEENAGE BEN OMNITRIX、道具编号与 FINAL 等制作字段；这些标记可读，但转载账号不是已确认的官方原发布者。

图中宽腕带为浅灰色，边缘绿色；上盖为黑色折面菱方轮廓，绿色边线沿转折延伸。近侧有三枚小绿色矩形，静图没有证明它们是按钮。圆盘藏在盖内，尺寸小于整体盖面；升起后是带绿色符号的黑色短圆柱，不能替换为覆盖整个腕带的大型银色筒体。

模型稿展示闭盖、露出圆盘、圆盘升起三种状态，但未证明铰链位置、滑轨方向、连续路径或时长。早期页面据此设计过面盖移动；当前 OV 保留完整原单盖且固定，不再提供双片滑盖。原圆芯的运动仍是项目绑定，不构成逐帧认证的原作机构。

## 全息人物仍有明确边界

手表具有真实网格体积，外星人投影仍是透明图片与剪影分层。人物、光束和环形头像不会因此成为完整三维角色。图层位置、遮挡、光效和视差可以跟随表盘，但不能声称已可查看角色真实背部或连续三维转身。

## 验证范围

当前验证应分别核对源包与网格哈希、AF／UA／OV 保留面映射、Reboot LoD 表面抽样与源细节、原件可动能力及实际浏览器呈现。源等价的含义是记录变换后的保留面一致，不能推导源本身没有交叠；LoD 的抽样距离不能冒称逐面等价。

渲染器、加载器及当前源模型的测试文件分别为 `tests/watch-model.test.mjs`、`tests/watch-model-mesh-loader.test.mjs` 与 `tests/watch-model-source-meshes.test.mjs`。最终运行构建哈希、完整测试、四款实际浏览器截图和包核验统一记入 [0.6.7 验证记录](review-v067.md)。早期头像构建或已撤回重建方案的检查不替代当前方案的证据。

数值入框、源网格核对与离线正交视图不等于真实手机帧率、SillyTavern／SillyDroid 安装、完整机械配合或用户视觉接受。外观参考研究继续保留在 [四代表型来源说明](watch-generation-reference.md)，与当前源文件身份分开。
