# 0.3.2 交付验证记录

本版修复手机覆盖工具在无需替换文件时漏查并发修改的问题，并新增 Diamond Matter 剪影。原目录安装、修复和更新继续使用[同一条手机命令](mobile-install.md)，无需删除旧目录。

## 手机覆盖修复

旧代码根据下载前的文件快照判断“无需覆盖”，随后直接返回。若另一进程在本地缓存暂存完成后修改目的文件，工具可能误报文件已一致。现在该分支也会重新核验目的文件；正常覆盖仍在取得安装锁后复核。检测到变更即停止，保留外部修改，不覆盖、不新增备份。

回归测试使用另一 Node 进程实际修改目的文件，在旧实现上失败、修复后通过。手机安装专项 **28 项通过**，完整 `npm test` 为 **82 通过、0 失败、0 跳过**。这些测试使用一次性目录，没有访问或写入用户手机。

## 新增剪影

224 条形态记录中 **175 条已有剪影，49 条待补**，不是独立物种数。新增 Diamond Matter 的完整身体来自[社区介绍视频](https://www.youtube.com/watch?v=1SxwSbOjghg)约 17 秒处的中心面板，视频全长 34 秒。画面带名称和 Petrosapien / Galvan 混合说明；原面板作者和上游发布未知，不作为官方出处证明。

源身体约 136×148 像素。内置 imagegen 保留头部晶体、不对称双臂、两腿和两脚，提取为透明背景；面部、手指脚趾、胸章和晶面经过 AI 放大重绘。主代理和独立代理都实际查看了原图及输出。完整提示词、来源与输出哈希保留在 `assets/extra-art.json`，原位图字节未在生成工具外修改。

淡 alpha 残留仍存在，菱形包络计入全部正 alpha 像素，因此表盘内的可见身体比例偏保守。没有把这张图宣称为官方透明素材，也没有据社区截图新证实原集时间点。
