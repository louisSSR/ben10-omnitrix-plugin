# 0.6.1 头像增补

本轮将环形转盘头像覆盖从 27 条增至 38 条，资源从 27 个增至 34 个。新增 Walkatrout、Juryrigg（OV）、Spitter、Bullfrag、Alien X、Big Chill（OV）、Mad Way Big；另为三个 Whampire Skurd 手臂状态和 Kickin' Hawk 钻石臂状态逐项对照并显式复用宿主头像。未改变 236 条目录与 235 张全身图。

新增 6 张 DNA Altering WebP 保留原字节，社区转载彩色对照不等于官方首发证据。Mad Way Big 使用用户提供图稿右上橙色头像作为参考，通过内置 imagegen 制作独立灰阶 RGBA PNG，供同一套配色矩阵使用。单锯齿高冠、双眼、颊线与侧管保留；比例较修长、管口为椭圆、灰阶有轻微变化与原生边缘噪点。未伪称精确抠图或官方原画。完整提示词保存在 `prompts/mad-way-big-portrait.txt`。

构建支持原尺寸 PNG 头像及原有 WebP；依旧检查安全文件路径、哈希、尺寸与 Alpha，不从任意外链加载头像。图标的显示坐标使用各自实际尺寸，未把 1254px PNG 错当 150px WebP。

- 完整自动测试 142/142 通过；包装器补充 PNG 原图与提示词路径后，相关 7 项回归通过。原 27 个头像和原有全身运行图片字节保持。
- 当前构建中逐项选择全部 11 个新增绑定，实际选中头像 ID 正确；清除搜索后恢复 236 条目录，手表常规切换池保持 235 项。
