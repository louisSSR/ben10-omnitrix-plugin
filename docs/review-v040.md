# 0.4.0 多视角立体手表

四代手表各增加四个观察角与收起／弹出两种状态，共 32 帧。外星人资料保持 184/224 条已接入剪影、40 条待补；投影、转盘与菱形表盘继续共享同一 Core/UI。

## 画面与交互

投影和转盘使用分别绘制的“上方、左前、低角度、另一侧”视图。不同视角可见表壳厚度、侧面按钮、弯曲腕带与内腔；表体只作平移和等比缩放，不再把正面图压扁成水平装置。菱形模式沿用独立正面美术与交叉挡片。

收起表芯会隐藏投影，弹出后光源按当前帧的表芯顶面定位。切换使用 180ms 的新帧淡入，减少动态时直接切换。这里有两个预绘机械状态，没有连续的升降轨迹；不同帧之间也没有保证逐像素注册。四个观察角不等于可任意旋转的三维网格。

环盘模式按每帧的偏心表芯平移整个装置，使表芯与环面共同位于舞台水平中央；按偏心程度限制整帧宽度，避免长护臂把环面推到边缘。转盘仍有八个可选择槽位和远近缩放。

Ultimatrix 左前弹出帧曾混入相邻图格的一条细线，现只对该帧左侧 3% 空白区作 CSS 裁帧；原图字节、发射点和真实表体均未因此重绘。

## 参考与推演边界

初代图集使用已有 V3 正面重绘作身份参考；该款的官方动画结构查证见 [表型依据](watch-generation-reference.md)。AF 图集直接参考已实际查看的官方动画收起／升芯截图。UA 的平面插图镜像最初发布链未证；OV 的制作模型稿镜像保留制作字段，但原始公开发布链未证。

四组都是 AI 参考重绘，不是官方透明原图或精确模型复刻。不可见的背面、内腔扣合和部分升芯机构属于绘制推演；相机角度只是观察类别，没有精确测量。四张原始透明图集、完整提示词、参考角色、局限与 SHA-256 保存在 `assets/watches-v4/`。运行包保存原字节副本。

## 验证

最终构建后串行执行 `npm test`：**104/104 通过，0 失败、0 跳过**。覆盖视角及表芯状态、偏心布局、加载失败回退、快速切换与减少动态，并保留搜索结果不限制英雄切换、挡片换影和安装覆盖等回归。一次包装夹具缺少新增元数据，补齐后全套通过。

桌面四代表的四个弹出视角，共 16 张实际截图逐张查看；表芯发射点基本贴合、侧壁和腕带内腔可辨。最终主预览还检查了收起／弹出与残边修复。桌面外部视口 1280×720，文档实际可用宽度 1265px。

手机模拟文档实际可用宽度为 **375/305px**，外框标注为 390/320px。投影检查四代表、上方／低角度、收起／弹出，共 32 组：无页面横向溢出，投影可见性正确。AF 与 UA 左前投影另有实看截图。环盘修复后检查四代表、全部四角、收起／弹出、两种宽度，共 **64 组**：环面左右边界均在舞台内，水平中心误差小于 0.01px。修复前确有 UA 环面被舞台裁切，未用“页面无溢出”替代舞台边界验证。

另检查了手机正面菱形盘的火焰人、超能兽与英雄切换；多视角工具栏在该模式隐藏。主预览控制台未见错误；手机测试容器出现一条无来源 URL 的 `MutationObserver.observe` 参数错误，不能确定来自插件，亦不宣称容器零错误。截图与结构化证据见 [浏览器记录](browser-qa-v040.json)。
