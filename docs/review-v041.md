# 0.4.1 素材更新

新增 Tyrannopede、Buglizard、Arctiguana。现为 **187/224 条已接入剪影、37 条待补**；记录包含版本、融合及身体状态，不等于独立物种数。四代手表的 32 帧多视角素材、表芯切换、三种选择模式及共用 Core/UI 均保留。

## 来源与边界

Tyrannopede 与 Buglizard 来自实际播放的 Cartoon Network UK 角色资料卡：前者 6.4 秒完整侧身及 12.8 秒面部辅助，后者 5.63898 秒完整侧身。保留长尾、足爪、角或巨嘴的主轮廓；小图放大的牙齿、甲片和指趾属于 AI 参考编辑，并非官方透明原图。两图少量低 alpha 残留如实记录，运行图与生成输出保持原字节；当前三种模式未见明显矩形底或主轮廓裁切。

Arctiguana 使用 TheHawkDown 已公开的原生透明社区画稿。黄眼、黑白服装、左前臂表标与背鳍支持初代造型推定；原页面没有明确标注版本，动作、头部和手指比例有社区风格。原作辅助截图下半身被遮挡，因此没有把该社区全身姿势称为原作复刻。未重新生成或改写像素。

完整来源、原始截图、输出哈希和生成提示词见 assets/extra-art.json。本批没有把机械 Alpha 错列为其变身形态；来源裁切或无法核实的记录继续保留待补。

安装包复核发现历史来源档案中 16 张参考截图的文件名为 `.png`、实际编码为 JPEG。本次确认这些文件与 0.4.0 Git 基线逐字节相同，保留旧路径及原始证据，没有重新编码；本批新增截图使用正确扩展名，运行图片格式检查正常。
