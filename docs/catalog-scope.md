# 目录范围与素材计数

当前 0.4.6 的目录有 224 条记录，其中 222 条已接入剪影、2 条保留缺图标记。这是对现有目录的计数，不是所有作品的穷尽性结论；记录还包含版本、融合和身体状态，不能直接解释为 224 个独立物种。

当前已登记的两条缺图是重启版 Ripjaws（`reboot-ripjaws`）和 Crabdozer（`nemetrix-crabdozer`）。Ripjaws 的既有小图尚缺足够的版本及使用者对应证据；本次实际查看的两条新增社区线索分别是梗图和独立重新设计，未采用。Crabdozer 尚未取得可采用的新透明原素材。未把其他版本或社区重设代替它们计为完成。

本次复核的目录源档保留 `coverageComplete: false`，范围是外星人变身形态，不包含普通人类或一般角色。源档还列有版本轮廓、Skurd 局部 DNA、DNA Lab 游戏来源、漫画及其余媒介的待核范围。这些是继续审计的线索，不是已证实缺失条目的数量，也不应只凭旧标记自动扩大目录。

后续条目需要先确认作品、出现依据及是否属于变身，再核对是否已用另一名称登记；取得合适素材并完成界面检查后，才计入“已接入”。素材来源、造型身份、界面显示与全作品覆盖是不同的检查项。

本次仅澄清范围，未更改运行代码、素材和版本号。0.4.6 的 104 项自动测试及浏览器检查仍是上一版的验证记录；本次文档校对不代表重跑测试、真实手机验收或全部形态已完成。
