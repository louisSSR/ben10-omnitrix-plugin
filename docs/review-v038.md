# 0.3.8 选择器与动效修正

本次针对搜索只剩一个英雄、环形盘位置与动感、表盘切换机构、全息装置方向和立体感进行修改。素材数量未变：224 条记录，184 条已接入剪影，40 条待补。188 张运行图片均与 0.3.7 保持相同字节。

## 行为与画面

- 档案搜索与手表选择池分离。搜索 Diamond Matter 仅有 1 条结果时，转盘仍有 8 个槽位，下一项能进入 Heat Jaws；搜索无结果时仍能切换至 Fourmungousaur。筛选不再偷偷改动当前英雄。手动选择待补素材仍会显示待补标记。
- 环面以表芯中央为圆心，大沙漏居中；环面扇区跟随拨动转动，英雄沿环面从 0.70 倍到 1.25 倍缩放，支持点击中央锁定。实际 DOM 中观察到中间角度与不同缩放矩阵，非仅有静态终点。
- 初代表盘保留固定外壳和英雄，双挡片在内部交错收拢、遮挡后换图，再展开。760ms 动作在 364.8ms 换图，273.6–456ms 为完全遮挡窗口。连续快速选择、切模式和减少动态会取消旧定时及动画，保留最新选择。参考视频的观察范围与推演部分见 [动画依据](dial-animation-reference.md)。
- 水平投影装置增加表身厚度、升降圆柱芯、光锥、较紧的深度层及基于透明轮廓的浮雕光照。它是 2.5D，不具备完整角色网格或不可见背面。四张表壳沿用此前透明美术，没有冒称本次完成官方原图重绘。
- Ultimatrix 长护臂与完成版横表单独调整比例和位置；投影宽度按发射点两侧剩余空间限制，防止宽体形态越界。

## 验证

最终构建后串行执行 `npm test`：**96/96 通过，0 失败、0 跳过**。包括三个模式的独立搜索池、空结果继续导航、待补素材选择、挡片遮挡窗口、快速切换及动画取消等回归。

实际浏览器检查桌面 1280px 外部视口，以及手机模拟 iframe。模拟器外框标注 390/320px，本次实测文档可用宽度为 **375/305px**（滚动条占用空间），两者均无页面横向溢出。检查了宽体 Fourmungousaur、Atomic-X 和初代火焰人的布局；Ultimatrix 与完成版投影修正后表身完整留在各自舞台内。

主预览控制台未见错误。手机测试容器记录到 3 次 `MutationObserver.observe` 参数错误，未提供来源 URL；不能证明来自插件，也不能据此宣称整个容器无错误。页面选择与布局检查仍完成。

过程中的一次构建与测试并行读取导致两项产物一致性检查失败；已停止并发，冻结源码后重新构建和完整测试通过。最终 CSS 窄屏补丁后再次串行检查通过，以上 96/96 对应最终产物。

截图与结构化结果见 [浏览器验证记录](browser-qa-v038.json)。未安装或操作用户手机上的 SillyDroid/SillyTavern，未运行真实宿主模型连接，未进行用户视觉验收。
