## 手表网格与材质

当前选用的网格注册表 SHA-256 为 `72be7a2a3b7c124b16d1a96e9995c6611d65ef0f8f7038bf92008aefdd6d7c5e`。第一槽按用户指定改用 Reboot 第一季表款；四款分别为 Reboot 120,000、AF 18,158、UA 9,274、OV 18,562 个三角。运行网格数分别为 4、1、2、7，UA 的三个原侧面组件合并存放在同一个固定网格文件中，原来的相对位置保留。

Reboot 使用新提供 3MF 中的 cuff、Dial、Core、button 四个原件。原 1,315,562 面经 QEM 减面得到手机显示用的 120,000 面版本，保留四件及同一统一缩放，没有体素重建、补形或新增盘盖。原始高模及其完整面数四视图仅用于离线对照，不是手机实际加载的网格。AF、UA、OV 不再使用中途的体素重建版本，而是按记录的刚体变换与统一缩放保留源三角坐标；OV 转为 float32 后恰好零面积的 16 面被省略并逐面记录。源外形、既有沟槽和源自带交叠保留，不能称为全部几何缺陷已修复。

只有实际独立的源件参与表芯运动：Reboot 的原厚 Core 可升降，OV 原圆芯及面环共用升降组；AF、UA 整表没有另造的核心，投影模式的按钮只开关人物投影。OV 完整单盖固定保留，未切成两半，也没有滑盖动画。源文件没有给出经确认的骨架和动作时长；这些装配位置和移动距离仍属项目设计，Reboot 盘芯与盘环的内部尺寸也未证明机械相容。

配色只写入原件及原表面特征的材质分类，没有新增黑色盘盖、沙漏薄片、升降轴或轴侧标记。显示使用程序计算的粗糙度、物体空间细纹和棚灯高光；它们不是源 RGB、扫描材质或实测 PBR 贴图。当前法线采用 40° 内相邻面连续扇区的角度加权计算，不平滑移动原几何顶点。详细来源、参数及限制见 [模型说明](watch-model.md)。

离线原件与 LoD 同相机对照已实际查看，四个小灯、沙漏刻槽、腕孔内壁及按钮均保留；这只支持所查看角度的形体对照，不等于连续表面误差上界、机械无交叠或手机体验通过。当前原件方案另有与本次注册表、渲染器及 CSS 哈希对应的 2,560 组全顶点入框数值检查，全部通过，最小舞台边距约 2.013 CSS px；范围为投影与转盘、指定宽度、四个相机端点和源件运动采样，不含视角插值、人物投影、光晕、标签或实体手机。禁用的源件运动参数只会重复固定几何，不表示存在可动盖。中途重建版本的闭合、自交及旧入框结果不作为当前原件方案的通过证据；此前导出的工作版、修复版也不能自动等同于当前运行模型。

APK 开表及英雄切换目前只有[静态动作参考](dna-altering-motion-reference.md)和独立私有候选，尚未接入本版交互。三种选择界面继续使用同一目录；人物投影仍是图片分层，没有变成可从各方向观察的三维角色。
