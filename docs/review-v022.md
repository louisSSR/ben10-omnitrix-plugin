## 来源与素材检查

- 两张融合形态来自设计师 [Thomas Perkins 的最终设计稿](https://thomasperkins.blogspot.com/2014/10/portfolio-work-atomic-x-and.html)。该页说明用于 Omniverse 第 51 集。保留原始合照 JPG，并用内置图像生成工具分别生成透明参考编辑稿；不是官方透明原图或逐像素抠图。双角、四臂四手、双脚和卷尾分别与原稿实看核对，细线、星点及阴影有生成变化。
- [终极神力暴龙](https://ben10hero.com/ultimate-forms/ultimate-humungosaur/) 和 [终极重力蟹](https://ben10db.weebly.com/omniverse.html) 沿用社区转载的透明原图，原字节直接内嵌。前者是绿色徽章的 AF/UA 形态；后者是红徽章的 OV / Albedo 形态，保留周围三颗独立小行星。来源边缘紧贴画面，无法证明上游未裁切的完整画布。
- [Omni-Kix XLR8](https://www.zazzle.com/going_hero_omni_kix_xlr8_poster-228995890155624054) 依据留存商品预览制作透明参考编辑稿。原海报与输出均实看，跑动姿势、双臂、弯腿、圆脚和卷尾保留；没有将商品来源宣称为官方动画原画。输出边缘有 49 个 alpha=1 的微弱像素，原始 alpha 保留，适配测量包含这些像素。
- 原始文件、显示输入、SHA-256、完整生成提示词和当前 UI 查看标记保存在 `assets/extra-art.json`。独立复核确认四张融合/终极输入的身份、身体部件和哈希；根执行者另行查看装甲 XLR8。没有用其他角色冒充未取得素材的形态。
