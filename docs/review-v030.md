# 0.3.0 交付验证记录

本版将不断增大的内嵌图片 HTML 改为离线目录包，并同步升级手机覆盖安装器。四代手表、三种召唤方式、选择动画和酒馆适配继续使用同一套 Core / UI，没有增加第二套产品。

## 安装与容量

- `preview.html` 从 56,951,586 字节降到 **252,807 字节**。原 172 个位图引用逐个解码，与新目录里的文件逐字节比较，全部相同；没有重新压缩、裁切或修改原图像素。
- 当前运行清单有 179 个文件，连同清单共 **45,106,830 字节**。新增图片按内容 SHA-256 命名，页面只引用本地资源。数字只说明交付体积，不代表测得了手机峰值内存或加载速度。
- 页面需要与 `assets/runtime/` 一起保存。当前自动浏览器只允许 HTTP/HTTPS，拒绝了 `file://`；未尝试绕过，直接双击打开仍是未验收边界。浏览器检查使用本地 HTTP 服务。
- [手机安装入口](mobile-install.md)仍用同一条命令。工具读取同一提交的完整清单，逐文件暂存、验证 SHA-256 和 Git blob，再备份和覆盖。素材先写，`manifest.json` 最后写；相同本地文件经完整校验后复用。原目录及无关文件保留。
- 保持 64 MiB 单文件、256 MiB 整包含清单、512 条目的限制。Git 属性固定运行文件字节，避免换行转换破坏已记录哈希。发布前另核对暂存区里的 Git blob。

迁移数字和基线提交见 [字节迁移收据](asset-migration-v030.json)。强制退出后的再次运行已在测试目录验证；整个目录不是断电原子事务，未声称覆盖所有强杀时刻或真实手机文件系统行为。

## 新增剪影

224 条记录中 **170 条已有剪影，54 条待补**。

- Stink Arms：[Cartoon Network 官方视频](https://www.youtube.com/watch?v=g2stvpcjeaE)中实际观看到的坐地姿态，播放器显示约 7:45。原始视频区域截图保留完整可见身体与翼尖。参考编辑保持坐姿及自体遮挡，没有换成臆造的站姿；脸、翼脉和指趾细线经过 AI 重绘。时间来自观看时 UI，不宣称精确帧或毫秒定位。
- 重启版 Big Chill：[社区动画 GIF](https://tenor.com/view/ben-10-reboot-alien-x-vs-big-chill-gif-13963413689486390802)中的完整飞行姿态，来源身体仅约 80×75 像素。保留 GIF 原字节、无损解码的第 145 帧和编辑输出；GIF 时间不等于动画正片时间。社区来源未核实为官方上游，放大后的内线与细肢不是官方高清细节。

两张均使用内置 imagegen 参考编辑，原图与输出均实际查看。两阶段完整提示词、哈希、来源链和差异在 `assets/extra-art.json`。它们不是官方透明原图或逐像素抠图，仍有宽范围极淡 alpha 残留；适配继续计入所有正 alpha 像素，未用阈值改写位图。淡残留使表盘中的主体偏小，但主要身体轮廓完整可见。缺少可靠完整轮廓的其他形态继续显示待补。
