新增 OV 极冻魔、电影《Alien Swarm》版 Nanomech 和《Heroes United》版 Shocksquatch。后两者的三维金属/二维灰白形态各自保留来源版本，不替换既有 UA Nanomech 或黄黑 OV Shocksquatch。

目录从 225 条 / 98 张剪影变为 **224 条 / 101 张剪影 / 123 条待补**：新增三张素材，同时合并原本重复的两个 HU Shocksquatch 记录。旧 ID `shocksquatch-hu` 继续可搜索，旧保存选择自动迁移到 `shocksquatch`。未把合并记作补图，也未将作品版本数量称为独立物种数量。

## 素材与显示

- OV 极冻魔沿用已查看来源图的既有 200×240 原生遮罩。旧暂缓结论针对已删除的记录墙小卡，本版在当前菱形表盘重新查看：四翼、前爪与双腿轮廓完整置于菱形内。原始转载链未证实为官方发布。
- 电影版 Nanomech 与 HU Shocksquatch 使用内置图像生成工具去背景的参考编辑稿。原画、透明编辑稿、SHA-256、完整提示词和观察差异见 `assets/extra-art.json`。细节及局部轮廓有生成变化，非官方透明原图，也非逐像素抠图。
- 两张较高分辨率的彩色透明输入原字节内嵌，UI 滤镜形成黑剪影或绿色投影。适配算法支持任意宽高的输入，按全部正 alpha 像素及等比居中映射计算菱形包络；没有用阈值去掉淡边来虚报安全余量。
- 手机布局将锁定按钮独占一行，避免按钮挤压角色名。

## 构建与验证

`preview.html`：9,061,946 字节，SHA-256 `2faed3bc6b750792683ec5a5791806d1228d8d602480cce010afd7986f0acc38`。

`npm test`：**58 项通过，0 失败，0 跳过**。包括 101 张剪影的逐像素菱形包络核对、旧 ID 偏好恢复、离线内嵌与构建一致性、动画中断、宿主交互边界以及 12 项手机覆盖安装测试。

新增 14 项素材管线测试。独立审查先复现三个问题：Python 优化模式会移除 assert 校验；合并记录遗漏旧别名；只检查 PNG 头可能让截断图片在输出后才报错。现对补充素材和基础快照都使用显式异常、合并所有旧别名，并在写入前核验 PNG 结构及完整解码。相关失败夹具与重入、哈希、未审查标记、重复导入测试均通过。此检查不承诺磁盘写入故障时四个资源输出为原子事务。

本版浏览器证据见 [browser-qa-v021.json](browser-qa-v021.json)：390×960 查看三张新增素材，320×920 操作 HU/OV 两种电力雪怪的转盘并确认远近缩放交换，1280×720 查看重校准表的投影。无横向页面溢出，未记录控制台警告或错误。手机名称和按钮的布局已实际查看。四代表型结构、官方与社区参考的界限仍见 [watch-generation-reference.md](watch-generation-reference.md)，本版未另外重绘四代表壳。
