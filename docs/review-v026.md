# 0.2.6 交付验证记录

本版新增 3 张剪影：224 条记录中 **168 条已有剪影，56 条待补**。四代手表、三种召唤方式与原有选择动画继续共用同一套界面。

## 新增素材

- 漫画版小奇兵：[出版社第 2 期 Robert Hack 变体封面](https://2001.dynamite.com/htmlfiles/viewProduct.html?PRO=C72513036343502011)。保留完整可见站姿和手持铅笔，移除书堆、地面与封面背景。铅笔是原图中的道具，剪影包含它。目录中的故事登场信息与封面来源分开记录。
- Slamworm：[Art Bully 游戏制作作品集](https://www.artbully.co/ben-10-characters)。取原图左侧大主视角，保留头角、侧肢、弯曲分节身体与尾端，移除右侧背视图。**游戏模型不等于动画原画**；界面来源说明已标注。
- 终极 Panuncian：[社区透明图转载](https://www.pinclipart.com/maxpin/TTiibT/)。原图有一个独立淡蓝方块，编辑后去除；保留四足、长牙、角、鬃毛与钩尾。原图尖端贴边，其上游完整性仍未知，没有把加边距当成找回丢失像素。

三张均使用内置 imagegen 参考编辑，未使用 CLI。源图与生成图已逐张实看，并有独立复核；原始字节、SHA-256、完整提示词与限制见 `assets/extra-art.json` 和 `assets/source-art/`。细线、面部、脚趾、纹理等存在 AI 重绘，不是逐像素抠图，也不宣称官方透明原图。工具图片展示中的灰雾不直接等于不透明背景；小奇兵背景采样 alpha 为 0，实际表盘剪影已核对。若干很淡的孤立 alpha 像素仍保留。

Hypnotick 的试稿扩大了源图无法确认的翅膀轮廓，未纳入。Omnitrix Glitch 七融合的游戏漫画原图裁断双脚，不能用另一个变身阶段拼补；其余裁切、版本未核或无法取得的素材继续标为待补。
