# 0.3.5 素材更新验证记录

本版新增 Crashocker 与 Benzarro Snare-Oh，当前 **181/224 条已有剪影，43 条待补**。记录包括作品版本、融合及身体状态，不等于独立物种数量。原有 183 张运行图片逐文件 SHA-256 不变，新增 2 张，运行图片共 185 张。

Crashocker 依据 [UB CRASH 社区解说视频](https://www.youtube.com/watch?v=QuVkcAJsyXk) 342.5 秒的完整腾空动作，以及 339.999987 秒的头颈近景。完整身体在截图中约高 180 像素；放大后的手脚、头冠和颈部细节含 AI 解释。两个镜头均实际查看，没有把频道认证标记当作 Cartoon Network 官方来源。

Benzarro Snare-Oh 依据 [Tenor 社区动画 GIF](https://tenor.com/view/benzarro-benzarro-10-ben-10-oliver-10-snare-oh-gif-9279218749286041843) 第 8 帧的完整蹲伏动作。GIF 426×240，第 8 帧对应 GIF 内 530ms；这不是原动画的集数或时间认证。保留原 GIF、解码源帧与透明输出，原帧像素绑定已核对。条带、手指脚趾连接和细线有重绘。输出底边少量低 alpha 残留和主体仅约 5 像素的原始下边距明确记入来源记录。

两项均为参考指导的 AI 透明编辑，不是官方透明素材或精确抠图。根代理实际查看源图与输出，然后在桌面查看已稳定的黑色菱形表盘和绿色投影；Crashocker 在目标 390px、Snare-Oh 在目标 320px 的 iframe 再核对同样两种模式。实际客户区宽 375/305px，均无横向溢出。头冠、双手和双脚都留在菱形内，没有看见独立背景黑块。低 alpha 像素保留在适配计算中，原位图没有再加工。

三种界面继续使用 [0.3.3 的实现](review-v033.md)：居中环形选择、菱形两瓣闭合后换影、水平手表与升起表芯。投影是有视差的 2.5D 分层，未制作完整三维角色模型；菱形动画时序仍是交互设计推演，参考视频未完整捕获的部分不宣称已经还原。

最终自动测试 **93/93 通过，0 跳过**。预览 273923 bytes，SHA-256 `819855cbf03e45f3253e92446f4a589bd2d818be073cf163e26fe2ab2498ace9`。运行清单 190 文件，另有 runtime-manifest.json。截图与尺寸记录见 [浏览器核对](browser-qa-v035.json)。生产页 error 记录为空；手机 iframe 测试壳仍有一条未定位来源的 MutationObserver.observe 错误，不能据此宣称所有控制台无错。
