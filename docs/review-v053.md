# 0.5.3 手表精修与三项 Whampire 状态

四代表身继续使用同一组三维几何与实际遮挡，并细化材质和零件层次。新增 Whampire 的 Skurd 钻头臂、双积木炮、吸能臂；当前 **235 条记录、233 张剪影、2 条已登记缺图**。这三项是已有变身的局部 DNA 状态，不是三个新物种。

## 手表改动

- 同一实体网格继续提供四个相机角度和机械升芯；表盘锚点、升芯行程、四代主体结构及控制件数量不变。
- 将表壳涂层、橡胶内腕带、金属护架、深色玻璃和绿灯分为五种材质；金属与玻璃使用静态解析式灯箱反射和菲涅耳边缘高光，绿色灯使用受限自发光近似。
- 表圈增加抛光唇边、内圈垫片和下部装配缝，形成有实体厚度的三层层次，保持可选表盘区域。
- 初代四条圆滑细护爪改为稍宽的八边倒角截面，保留弯曲路径；初代四枚小灯改圆顶嵌入镜片，大侧键保留独立更大规格并增加嵌套垫片。
- AF 两侧控制件改嵌入圆顶灯，前部银弧增加平面倒角；UA 两根独立管线末端增加镜片，未增加管线；OV 三枚标记及两块独立盖片保留。
- 腕带原有外沿增强、内壁分材质，并增加两条很浅的成型接缝；没有附加任意装甲板、文字、螺丝或新开关。
- 维持每代 2/2/2/4 个绘制批次和 40 字节顶点格式，无纹理包、网络资源、随机噪声、额外后期渲染或空闲持续重绘。
- 根据实际首版截图集中校正：将材质色明确放在线性光照空间，输出采用 sRGB 显示映射和轻度高光压缩，区分近黑涂层、橡胶与内腕壁，同时降低银色反射能量、扩大灯箱过渡。
- 倒角护架保留横向硬边，但法线沿弯曲方向连续，去除由纵向分段平面法线造成的突兀亮条；删除固定水平反射亮带。几何顶点、结构、锚点和批次数未增加。

- 这是有限复杂度的程序化实体模型精修，不是官方 CAD、逐像素复制或物理光线追踪；背面尺寸、内腕腔及机械行程仍是已披露的建模解释。
- 运行图集是已生成的多角度美术参考，不将其中隐藏构造或视觉漂移当作官方定论。
- 反射来自少量固定解析式灯箱，玻璃采用不透明深色底面上的高光近似，没有透明折射、屏幕空间反射、纹理微表面或真实投影阴影。
- 全息英雄仍使用原有图片与投影呈现，本次未改为完整三维角色；本次没有增加自由旋转、背底视角 UI 或改变 Core/Host 集成。
