# 0.5.1 两项新增剪影

新增现代 Omniverse Kevin（Weapon XI 融合体）与 Humungousaur（Skurd 钻石臂与剑）。当前目录为 **230 条、228 张已接入剪影、2 条已登记缺图**。两项均是已有角色的融合或局部 DNA 身体状态，不是两个新物种。

## 来源与重绘范围

Kevin 依据 [Ben10Hero 的现代融合体参考](https://ben10hero.com/ben-tennyson-and-his-team/origins-kevin-ethan-levin/)重绘，保留多臂、异形双翼、黑色发束与绿色腿部。社区原图上缘翼尖、下缘脚部被裁；生成图补全它们，明确属于 AI 解释。原图首发、准确帧时点与复用许可未核实。宽翼和重叠手臂使黑剪影的细节辨认弱于彩色原图，不宣称逐像素恢复。

Skurd 的来源是根代理实际查看的 [Cartoon Network 官方片段 The Power of Skurd，17 秒](https://www.youtube.com/watch?v=zRI5HSkOdBE&t=17s)。保留俯视原姿势、普通手持晶体剑、另一只晶体前臂和完整双脚。806×453 的原始 JPEG 截图中人物较小；脸部、指节、胸章与晶面属于重绘解释。视频来源为官方不等于生成图为官方透明原图。

两张均使用内置 imagegen 各一次，保留生成原始字节，没有程序像素修改。原图、输出、完整提示词、SHA-256 与限制登记在 [素材登记](../assets/extra-art.json)。Kevin 强 alpha 轮廓未触边，但底部只有 8px 留白且左/底边有 alpha1 残留；Skurd 四边完全透明。菱形适配继续测量真实 alpha 包络。
